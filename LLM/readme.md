# LLM Chat Application

A modular chat application for interacting with Large Language Models (LLMs) with built-in authentication and database storage.

## Features

- 🔐 **User Authentication** - Secure user registration and login
- 💾 **Chat History** - Persistent storage of conversations
- 🖥️ **CLI Interface** - Command-line interface for chat operations
- 📊 **Database Management** - SQLite database for storing conversations
- 🔧 **Configurable** - Easy configuration via environment variables
- 🔌 **Multi-LLM Support** - Ready for OpenAI, Anthropic, and other LLMs
